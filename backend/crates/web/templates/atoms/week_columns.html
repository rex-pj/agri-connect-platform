{#- One weekly figure of the demand report as a column chart, drawn on the server (no script, no style attribute: the page CSP). `weeks` are the report's, oldest first (each with `starts_on`, `ends_on`), `figures` the matching application::outputs::Figure, `min` the smallest figure shown, `tone` the colour (a `week-columns__bar--{tone}` class), `label` what the chart counts (its accessible name). Each column carries its number above it and its week under it, so the chart needs no axis. The scale runs from 0 to the largest figure shown (at least `min`). A hidden figure is an outline at the height of "fewer than `min`", labelled so, never a zero; a zero is a hairline. -#} {% macro week_columns(weeks, figures, min, tone, label) -%} {%- set step = 40 -%} {%- set top = 16 -%} {%- set plot = 96 -%} {%- set foot = 18 -%} {%- set n = figures | length -%} {%- set width = n * step -%} {%- set base = top + plot -%} {%- set_global most = min -%} {%- for f in figures %}{% if f.value is number and f.value > most %}{% set_global most = f.value %}{% elif f.at_least is number and f.at_least > most %}{% set_global most = f.at_least %}{% endif %}{% endfor -%} {%- endmacro week_columns %}
